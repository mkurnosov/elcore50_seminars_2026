1. НПЦ ЭЛВИС (ELVEES)

  • Специализация — разработка микросхем для систем связи и телекоммуникационного оборудования

  • Образовано в 1990 году на базе научно-производственного объединения «ЭЛАС» (разработки в области космической электронной техники, 1960-80 гг.)

  • СнК «Гиперком-У» (К1892ВМ21Я, 2 DSP-ядра Elcore-50, MCom-03R)

  • СнК СКИФ (MCom-03)

  • Снк 1892ВМ248 RoboDeus (16 DSP-ядер Elcore-50)

  • Радиационно стойкий процессор 1892ВМ206

  • СнК 1892ВМ14Я (CPU ARM Cortex-A9, Elcore-30M)

  • ЭЛВИС техпортал: https://support.elvees.com

  • GitHub: https://github.com/elvees

4. Структурная организация СнК «Гиперком-У»

  • 4 ядра Cortex A53 с частотой до 1.2 ГГц (NEON SIMD, little-endian mode)

  • 2 DSP-ядра с архитектурой Elcore50 (VLIW SIMD DSP, little-endian), 405 МГц

  • 2 управляющих RISC-ядра: архитектура MIPS, 32 ядра, управляющее и служебное процессорное ядро, частота >= 560 МГц (little-endian)

  • GPU PowerVR Graphics Series8XE

  • VPU Mali-V61: HEVC/H.264 ядро кодера/декодера

  • IPS Felix v2505: ядро предобработки изображения и видеоввода

  • GNSS: навигационное ядро с поддержкой ГЛОНАСС/GPS/BeiDou/GALILEO

  • Контроллеры DDR памяти: DDR3/LPDDR3/DDR4/LPDDR4 (разрядность 32 бита на контроллер)

  • USB: USB 3.0

  • PCIe: PCI Express 3.0

  • QDMA: Четырехканальное DMA память-память

  • GEMAC: Ethernet/IEEE 802.3-2012 10/100/1000 Мбит/с

  • https://support.elvees.com/docs/Microchips/K1892VM21YA/

  • https://support.elvees.com/f/Процессоры%20Мультикор/K1892VM21YA/Документация/Manual_К1892ВМ21Я.pdf

Пиковая производительность одного DSP-ядра MAC (Multiply-Accumulate, 2 FLOP) операций за такт [https://tehnoomsk.ru/archives/4701]:

  • 64 MAC для формата FP64

  • 256 MAC в формате FP32

  • 1024 MAC в формате FP16

  • 8 MAC в формате INT64

  • 64 MAC в формате INT32

  • 256 MAC в формате INT16

  • 1024 MAC в формате INT8

Эффективное использование DSP требует явного использования в коде программы архитектурных возможностей Elcore50:

  • ILP: VLIW-инструкции из 8 слотов

  • Data parallelism: SIMD-операции

  • Совмещенные операций: MAC (Multiply-Accumulate)

  • Аппаратные циклы (zero-overhead loops)

  • Параллельный доступ к XRAM и YRAM за операндами инструкций

# Кросс-компилятор для ARM (aarch64)

# Кросс-компилятор для DSP Elcore50

Для сборки на базе CMake для каждого тулчейна поставляется toolchain.cmake-файл:

# mips32
buildroot/output/host/opt/toolchain-mipsel-elvees-elf32/share/cmake/toolchain.cmake
# elcore50
buildroot/output/host/opt/toolchain-elcore50/share/cmake/elcore50-toolchain.cmake

Использование CMake-файлов:

cmake -DCMAKE_TOOLCHAIN_FILE=<absolute-path-to-toolchain.cmake> ...

9. Процесс разработки приложений для СнК Гиперком-У

  1. Разработка ведется на хост-машине с архитектурой x86-64 под управлением GNU/Linux.

  2. На хост машине выполняется кросс-компиляция в код целевого процессора СнК: ARM Cortex A53 (aarch64), MIPS 32 (mips32 little endian), Elcore-50.

  3. Исполняемые файлы копируется по сети в СнК (scp).

  4. Исполняемые файлы запускаются на целевом процессоре СнК (ssh).

12. Модуль ядра elcore50

  • https://dist.elvees.com/elcorecl/docs/latest/components/elcore50.html

Модуль ядра elcore50 создаёт файл устройства /dev/elcore и по одному файлу устройства на каждое DSP-ядро /dev/elcore#.

Взаимодействие с устройствами осуществляется через системные вызовы: open(), ioctl(), close(), poll().

Функции модуля:

  • Отображение областей памяти пользовательского процесса в адресное пространство DSP.

  • Создание нового задания (job), постановка заданий в локальную и глобальную очереди на выполнение на DSP, отслеживание состояний.

  • Обеспечение согласованности данных между CPU и DSP для заданной области памяти.

  • Поддержка экспорта и импорта dma-buf.

Системные библиотеки:

  • elcore реализует интерфейс создания заданий, ожидания завершения, обработки системных вызовов DSP, работает напрямую с утройством через ioctl().

  • elcore-runtime функции для разработки DSP-библиотек (get_core_id(), elcore_spawn(), elcore_sync()), реализует системные вызовы.

  • elcorecl реализует для DSP аналогичный OpenCL функционал.

Исходный код библиотек: buildroot/output/build/elcorecl-master/libs

13. Запуск программы на DSP-ядре через ElcoreCL API

Программа запускается на ARM-ядре и средствами ElcoreCL API запускает на DSP-ядре 0 заранее скомпилированный ELF-файл.

Собираем два ELF-файла — для ARM и DSP ядер:

cd ex03-elcorecl-example

export BUILDROOT_SRC_DIR=/opt/eltay-sc-sdk-2025.09-linux66-20260928

cmake . -B build \
        -DCMAKE_TOOLCHAIN_FILE=$BUILDROOT_SRC_DIR/buildroot/output/host/share/buildroot/toolchainfile.cmake \
        -DELCORE_CMAKE_TOOLCHAIN_FILE=$BUILDROOT_SRC_DIR/buildroot/output/host/opt/toolchain-elcore50/share/cmake/elcore50-toolchain.cmake \
        -DElcoreRuntime_DIR=$BUILDROOT_SRC_DIR/buildroot/output/staging/usr/lib/cmake/ElcoreRuntime \
        -DElcoreCL_DIR=$BUILDROOT_SRC_DIR/buildroot/output/staging/usr/lib/cmake/ElcoreCL \

cmake --build build
